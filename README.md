# ⚡ LESCO Online Bill Check Portal

A fast, lightweight, and SEO-optimized static website designed to help users easily check, download, and print their Lahore Electric Supply Company (LESCO) duplicate electricity bills. 

🔗 **Primary Service Portal:** [onlinebilllesco.pk](https://onlinebilllesco.pk/)

---

## 🚀 Features

* **Instant Redirects:** Seamlessly guides users to the primary bill-checking portal.
* **SEO-Optimized:** Structured with semantic HTML5 tags and meta descriptions to rank well on search engines for terms like "LESCO bill check".
* **Responsive Design:** Fully mobile-friendly UI that adapts to smartphones, tablets, and desktop screens.
* **Lightweight:** Built with zero external dependencies, ensuring lightning-fast page load speeds.
* **FAQ Section:** Addresses common user queries regarding reference numbers and bill payments.

## 🛠️ Tech Stack

This project is built using core web technologies for maximum speed and simplicity:
* **HTML5:** Semantic structure and content formatting.
* **CSS3:** Custom, embedded styling for a modern and clean user interface.
* **Vercel:** Automated CI/CD deployment and global edge hosting.
